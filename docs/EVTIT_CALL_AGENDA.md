# EVTit / Black Dog Call Agenda — LumenCore

**Goal:** Turn the Terry / Bruno / Aron call into a concrete engineering-partnership path.

---

## 1. Opening summary

LumenCore is a proof-to-pilot AI infrastructure validation platform.

It helps buyers test AI/infrastructure claims against accepted baselines through controlled replay, locked metrics, evidence manifests, and buyer-readable proof reports.

---

## 2. What LumenCore needs from EVTit

The ask is focused:

> Help harden the live proof stack into a customer-ready replay-validation product.

Needed engineering support:

- product architecture review,
- web portal cleanup,
- replay runner productization,
- evidence manifest automation,
- customer proof report template,
- pilot intake flow,
- API cost/reliability controls,
- investor/federal demo packet support.

---
