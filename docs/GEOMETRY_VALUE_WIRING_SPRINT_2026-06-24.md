## Dollar Claim Gate

The system can discuss a value surface as a target market or conservative scenario. It cannot yet state verified dollar savings. A reviewer-grade dollar claim needs all of the following:

1. A named sector or asset class with a defensible public cost basis.
2. A frozen live replay window with hashable input data.
3. A baseline run on the exact same input window.
4. A champion run on the exact same input window.
5. A measurable delta with confidence interval or bootstrap interval.
6. A conversion formula from delta to operational value.
7. A sensitivity table showing low/base/high assumptions.
8. A statement that the result is replay evidence unless a real operator validates it.

Until those eight gates pass, the language should be:

"This evidence supports a bounded opportunity surface and a field-validation plan, not a verified realized-savings claim."

## What To Publish

- Guaranteed grant outcomes.
- Live profit claims.
- Verified government savings.
- Field validation claims.
