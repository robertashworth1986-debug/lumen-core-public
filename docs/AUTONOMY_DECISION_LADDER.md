# LumenCore Autonomy Decision Ladder

**Purpose:** Define what Luma/agents can do automatically, what needs review, and what must never be automated.

---

## 1. Green lane - automatic

These actions are low-risk and can be handled automatically:

- label Gmail threads,
- summarize new replies,
- create tracking notes,
- create calendar prep blocks,
- build internal GitHub docs,
- create draft packets,
- search Sweetspot for relevant opportunities,
- search Gmail for relevant responses,
- identify hot leads and deadlines,
- prepare call agendas,
- prepare non-legal business summaries.

---

## 2. Yellow lane - send with broad approval

These actions can be done when Robert has approved outreach for the lane:

- reply to warm investor or partner intros,
- follow up on meeting requests,
- ask for routing to the correct person,
- send proof-to-pilot scope links,
- send business plan only when appropriate,
- ask for grant/program eligibility clarification,
- send polite deadline reminders.

Use concise, bounded claims.

---

## 3. Red lane - explicit approval required

These actions require direct confirmation:

- legal filings,
- patent claim changes,
- grant final submission,
- accepting money or terms,
- signing contracts,
- sending confidential source code or sensitive IP details,
- submitting tax, bank, or government certification forms,
- anything involving passwords, keys, verification codes, or account recovery.

---

## 4. Never automate

Never share:

- passwords,
- API keys,
- login codes,
- bank details,
- identity documents,
- private family details unrelated to the business,
- unreviewed enabling patent details to external parties.

---

## 5. Core rule

Move fast on routing, preparation, summaries, reminders, and warm follow-ups.

Slow down on legal rights, government certifications, money, security, and irreversible submissions.
