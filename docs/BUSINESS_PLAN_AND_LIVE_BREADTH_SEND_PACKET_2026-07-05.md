## Live Breadth Agent Design

Agent 1: Source Harvester

- Validate configured provider keys without printing secrets.
- Pull small fresh snapshots first.
- Record row count, timestamp, endpoint, license/terms note, and hash.
- Fail closed if a provider returns thin, stale, or malformed data.

Agent 2: Replay Runner

- Convert each source into locked benchmark tasks.
- Run accepted baselines before champion families.
- Preserve train/test split, metric, seed, and environment.
- Write pass/fail and uncertainty, not just wins.

Agent 3: Evidence Freezer

- Hash every input, output, manifest, and report.
- Copy approved artifacts to the proof vault and public-safe feed bundle.
- Refuse anything containing secrets, private keys, raw credentials, or unsafe claims.

Agent 4: Reviewer Narrator

- Convert results into human-readable proof cards.
- Label evidence boundaries clearly.
- Route only validated public-safe summaries to the domain.
