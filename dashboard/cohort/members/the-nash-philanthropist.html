Three questions worth exploring

PUBLIC RESEARCH

These are hypotheses to discuss, with current baselines unmeasured. They do not establish that a problem or loss occurs in this business.

01OWNER INPUT NEEDED

Could event listings remain more dependable if each has a current organizer source and last-checked date?

An event-data checklist that flags missing dates, changed venues, cancelled events, and possible duplicates for an editor.

What we could measure together

Measure: Listings with a current verified date, venue, and organizer link (percent of active listings).

Agree eligible work, observation window, quality threshold and exclusions with the owner before comparing.

Acceptance boundary: No automatic publishing or assumed event status; preserve organizer sources and human confirmation.

02OWNER INPUT NEEDED

Could an organizer submit a complete event description with fewer editing rounds?

A draft submission template for event purpose, time zone, venue, cost, accessibility, ticket link, and the organizer-approved charitable-benefit wording.

What we could measure together

Measure: Clarification rounds before an event listing is approved (rounds/listing).

Agree eligible work, observation window, quality threshold and exclusions with the owner before comparing.

Acceptance boundary: Do not invent beneficiary relationships, charitable status, tax deductibility, or fundraising results.

03OWNER INPUT NEEDED

Could reporting distinguish platform attention from actual event attendance or contributions?

A small event report template that separates page views, outbound clicks, organizer-reported attendance, and verified contributions, leaving unknown fields blank.

What we could measure together

Measure: Promoted events with separately traceable engagement and organizer outcomes (percent of promoted events).

Agree eligible work, observation window, quality threshold and exclusions with the owner before comparing.

Acceptance boundary: Clicks do not establish attendance, donations, or causal impact; use only aggregate data the organizer is allowed to share.
