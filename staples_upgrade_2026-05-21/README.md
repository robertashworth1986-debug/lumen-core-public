# Staples Upgrade Pack

High-tech, geometric, holographic visual package for event-day printing and pitch delivery.

## Includes

- Business cards sheet
- Holographic flyer
- 8x3 banner source
- Ultra pitch deck (PPTX)
- Pitch script and style guide
- SVG QR set for investor, partner, customer, health, and snapshot lanes

## Use

Open HTML files in browser and print at actual size. Open PPTX for live screen pitch.
